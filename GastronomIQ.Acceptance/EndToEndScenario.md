2. Create supplier.
3. Create ingredient and unit.
4. Create recipe and recipe version.
5. Create stock location.
6. Create purchase order.

17. Submit menu performance.
18. Classify Star / Plowhorse / Puzzle / Dog.
19. Build operational dashboard.
20. Verify KPIs.
21. Verify audit events.
