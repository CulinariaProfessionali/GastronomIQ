# Menu Engineering Acceptance

1. Create a menu item for Branch A.
2. Set a current selling price.
3. Verify the price history is retained.
4. Attempt to analyze the item under Branch B.
5. Verify authorization failure.
6. Submit a branch-level performance set.
7. Calculate contribution margin:
   `Selling Price - Recipe Cost`.
8. Calculate food-cost percentage:
   `Recipe Cost / Selling Price × 100`.
9. Calculate average quantity sold and average contribution margin.
10. Classify each item as Star, Plowhorse, Puzzle or Dog.
11. Verify the classification is deterministic for the same input.
